# Olist E-Commerce Analysis

SQL + Excel project analyzing ~550,000 rows of real Brazilian e-commerce data (Olist dataset) to find where the business is losing revenue and customer satisfaction.

## What's in this repo
- `olist_project.sql` — full SQL script (table setup, data loading, and analysis queries)
- `Olist_Project_Writeup.docx` — full write-up with findings and recommendations

## Key findings
- Late deliveries drop average review scores from 4.29 to 2.57 (about 40%)
- Only 3.12% of customers place a repeat order
- Olist's delivery estimates were heavily padded early on, then became far more accurate over time

Built using MySQL, Excel/Power Query, and Power BI. (Used Claude AI as a learning aid while writing SQL and debugging.)
